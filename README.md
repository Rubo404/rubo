Rubo

Rubo is an experimental general-purpose programming language designed to provide a simple, readable, and flexible programming experience.

Features

- Custom syntax with ".rbo" file extension
- Lexer, parser, and interpreter
- Variables, conditions, loops, and functions
- Built-in library system
- Type system
- Error handling
- Debugging tools
- Runtime memory management

Requirements

- Python 3.12 or later

Getting Started

Clone or download this repository, then run:

python main.py Examples/01_hello_world.rbo

Project Status

Rubo is currently in early development. Features and syntax may change between versions.
